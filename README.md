# 🎓 ระบบเช็คชื่อนักศึกษาออนไลน์อัจฉริยะ (Smart Student Attendance System)
### Anti-Cheat 4-Layer Security • AI Face Recognition • Live Projector • LINE Flex Message 2.0

ระบบเว็บแอปพลิเคชันเช็คชื่อนักศึกษาระดับมืออาชีพ พัฒนาด้วยสถาปัตยกรรม **Single Page Application (SPA)** รองรับการทำงานทั้งบน **Google Apps Script (ฐานข้อมูล Google Sheets)** และแบบ **Standalone Web App / PWA บน GitHub Pages** ผสานระบบความปลอดภัยป้องกันการโกงขั้นสูง 4 ชั้น, ระบบ AI สแกนใบหน้าเช็คชื่ออัตโนมัติ, ระบบฉายจอโปรเจกเตอร์หน้าห้องเรียน, รายงานโพเดี้ยมรางวัล Live Selfie, แดชบอร์ดสถิติ และการส่งออกรายงาน PDF / Excel ครบวงจร

## 🎨 ระบบการออกแบบ UX/UI สไตล์ และโทนสี (UX/UI Design System & Color Palette)

ระบบได้รับการออกแบบโดยเน้นหลัก **Human-Centered Design**, **Mobile-First Accessibility** และ **Modern Skeuomorphic Glassmorphism** เพื่อมอบประสบการณ์การใช้งานที่ลื่นไหล สวยงามระดับพรีเมียม สบายตา และเข้าใจง่ายโดยไม่ต้องฝึกอบรม

### 🔘 2. สถาปัตยกรรมปุ่มกดสัมผัส 3 มิติ (3D Tactile Buttons)

ระบบใช้ปุ่มกดสไตล์ **3D Tactile Skeuomorphism** ที่ให้ความรู้สึกเหมือนปุ่มกดจริงในโลกกายภาพ:
* **ขอบบนนูนเรืองแสง (Top Inset Highlight)**: `border-top: 1px solid rgba(255, 255, 255, 0.35)` จำลองแสงตกกระทบจากด้านบน
* **ฐานล่างหนามีมิติ (Bottom Shadow Bevel)**: `border-bottom: 2.5px solid` สร้างมิติความหนาของปุ่มกด
* **การตอบสนองเมื่อกด (Interactive States)**:
  * **Hover**: ลอยตัวขึ้นเล็กน้อย `transform: translateY(-2px)` พร้อมเงาเรืองแสง (Glow) สว่างขึ้น
  * **Active (กดปุ่ม)**: ปุ่มยุบตัวลง `transform: translateY(2px)` และลดความหนาขอบล่าง ให้สัมผัสการคลิกที่หนักแน่นและแม่นยำ

```css
/* ตัวอย่างรูปแบบปุ่มกด 3 มิติสีส้ม Radiant Orange */
.btn-3d-orange {
  background: linear-gradient(180deg, #FF8533 0%, #FF6B00 50%, #E65100 100%);
  color: #FFFFFF;
  border-top: 1px solid rgba(255, 255, 255, 0.45);
  border-bottom: 2.5px solid #9E3300;
  box-shadow: 0 4px 14px rgba(255, 107, 0, 0.45);
  transition: all 0.16s cubic-bezier(0.16, 1, 0.3, 1);
}
.btn-3d-orange:active {
  transform: translateY(2px);
  border-bottom-width: 1px;
}
```

### 📱 3. หลักการออกแบบเพื่อประสบการณ์ผู้ใช้ (UX Design Principles)

1. **สรีรศาสตร์บนมือถือ (Mobile-First Ergonomics)**:
   * **Thumb Zone Navigation**: เมนูควบคุมสำคัญถูกจัดวางไว้ในบริเวณครึ่งล่างของหน้าจอเพื่อให้กดได้ง่ายด้วยนิ้วโป้งมือเดียว
   * **Horizontal Action Clusters**: ปุ่มจัดการนักเรียน (`[ 📸 ใบหน้า ]`, `[ ✏️ แก้ไข ]`, `[ 🗑️ ลบ ]`) จัดวางในแถวแนวนอนอย่างเป็นระเบียบ ไม่ตัดคำ ไม่ตกบรรทัด
2. **ระบบนำทางแบบทีละขั้นตอน (Step Progress Wizard)**:
   * ขั้นตอนการเช็คชื่อของนักศึกษาแบ่งเป็น 4 สเต็ปอย่างชัดเจน (1. เลือกตัวตน ➔ 2. ยืนยันพิกัด GPS ➔ 3. ถ่ายภาพเซลฟี่ ➔ 4. ยืนยัน OTP/QR)
   * ลดความผิดพลาดในการกรอกข้อมูล และเพิ่มอัตราความสำเร็จในการเช็คชื่อสู่ 100%
3. **การแก้ปัญหา Dropdown กลืนสี (High-Contrast Dropdown Fields)**:
   * ทุกช่องตัวเลือก (`select`) และเมนูป๊อปอัป มีการบังคับใช้พื้นหลังสีเทาดำอ่อน `#25252D` พร้อมตัวหนังสือสีขาวบริสุทธิ์ `#FFFFFF` ป้องกันปัญหาตัวหนังสือขาวกลืนกับพื้นขาวในเบราว์เซอร์มือถือ
4. **บัตรยืนยันตัวตนดิจิทัล (Virtual Digital Attendance Pass)**:
   * หลังจากเช็คชื่อสำเร็จ ระบบจะสร้างบัตร Virtual Pass กึ่งโปร่งแสง พร้อมภาพเซลฟี่ พิกัด GPS ระยะห่าง และเวลาที่บันทึก เพื่อให้นักศึกษาแคปหน้าจอไว้เป็นหลักฐาน

## 🌟 จุดเด่นและฟังก์ชันการทำงานหลัก (Key Features)

### 🤖 1. ระบบสแกนใบหน้าเช็คชื่ออัตโนมัติด้วย AI (AI Face Recognition Check-in)
* **โมเดลปัญญาประดิษฐ์ในตัวเบราว์เซอร์**: ขับเคลื่อนด้วย `face-api.js` (SSD MobileNet v1, Face Landmark 68, Face Recognition Net 128-d Descriptors) ตรวจจับและรู้จำใบหน้าแบบ Real-time โดยไม่ต้องพึ่งพาเซิร์ฟเวอร์ภายนอก
* **ลงทะเบียนใบหน้านักศึกษา (Face Registration)**: รองรับทั้งการถ่ายภาพสดผ่านกล้องหน้า และการอัปโหลดภาพถ่ายจากอุปกรณ์เพื่อประมวลผลคำนวณเวกเตอร์ใบหน้า
* **UX/UI สแกนใบหน้าบนมือถือแบบโปร่งตา**:
  * กรอบกล้องถ่ายทอดสดขนาดใหญ่ด้านบน แสดงกรอบสี่เหลี่ยมตรวจจับใบหน้า
  * กรอบรายชื่อนักศึกษาที่ **"สแกนติดแล้วในคาบนี้"** จัดวางไว้ด้านล่างจออย่างเป็นระเบียบ มองเห็นได้ชัดเจน
* **ระบบตอบสนองด้วยการสั่นเตือน (Haptic Feedback)**: เมื่อสแกนใบหน้าติดและบันทึกสำเร็จ โทรศัพท์จะสั่นเตือนสั้นๆ 1 ครั้งทันที (`navigator.vibrate(100)`)
* **ซิงค์สถานะเข้าสู่คาบทันที**: บันทึกการมาเรียนและดึงรายชื่อเข้าสู่ระบบในคาบปัจจุบันแบบ Real-time โดยไม่ต้องรีเฟรชหน้าจอ

### 🛡️ 2. มาตรการความปลอดภัยป้องกันการโกง 4 ชั้น (Anti-Cheat 4-Layer Security Engine)
1. **Dynamic Seed-based TOTP & Live QR Code**: 
   * รหัส OTP 6 หลัก และ Live QR Code ที่เปลี่ยนใหม่โดยอัตโนมัติทุกๆ 15 วินาที (หรือตามที่อาจารย์กำหนด 10s - 120s)
   * ป้องกันการถ่ายภาพหน้าจอ (Screenshot) หรือส่งต่อ QR Code ไปให้เพื่อนที่ไม่ได้อยู่ในห้องเรียน
2. **GPS Geofencing & Google Maps Picker**:
   * ตรวจสอบพิกัดละติจูด/ลองจิจูดจริงของนักศึกษาว่าอยู่ภายในรัศมีห้องเรียนที่กำหนด (คำนวณระยะทางด้วยสูตร Haversine Formula)
   * หน้าต่างตั้งค่าพิกัดสำหรับอาจารย์ พร้อมปุ่ม **ปักหมุดบนแผนที่ Google Maps** (ค้นหาสถานที่, สลับแผนที่ดาวเทียม, ลากหมุด) และปุ่ม `[ ใช้ตำแหน่งฉัน ]`
3. **Device Token Binding (1 เครื่อง / 1 บัญชี)**:
   * ผูกลายนิ้วมือดิจิทัลของอุปกรณ์ (Device Fingerprint) ป้องกันการนำสมาร์ตโฟนเครื่องเดียวมาเช็คชื่อแทนเพื่อนหลายคน
4. **Live Camera Selfie Only**:
   * บังคับเปิดกล้องหน้าเพื่อถ่ายภาพสดขณะทำการเช็คชื่อ ปิดการเลือกรูปภาพจากคลังรูปภาพ (Gallery) ป้องกันการใช้รูปเก่า

### 📅 3. ระบบเช็คชื่อประจำวันอัตโนมัติตามปฏิทิน & ตารางสอน (Smart Automated Schedule)
* **กำหนดตารางเวลาแยกตามห้องเรียนและวิชา**:
  * **เลือกได้หลายห้องเรียนพร้อมกัน (Multi-Classroom Selection)** พร้อมปุ่ม `[ เลือกทั้งหมด ]`
  * กำหนดวันในสัปดาห์ที่เปิดใช้งาน (จันทร์–ศุกร์ หรือเสาร์–อาทิตย์)
  * กำหนดกิจกรรม/วิชาที่เช็คชื่อตาม 4 หมวดหมู่
* **ช่วงเวลาแบบแยกเฟสอัจฉริยะ (Time Windows)**:
  * 🌅 **รอบเช้า (Morning Session)**:
    * เวลาเริ่มเปิดระบบ (เช่น `07:00 น.`)
    * 🟢 **หมดเขตมาตรงเวลา** (เช่น `08:30 น.`) $\rightarrow$ สถานะ: **มาเรียน (Present)**
    * 🌸 **หมดเขตมาสาย** (เช่น `09:00 น.`) $\rightarrow$ สถานะ: **มาสาย (Late)**
  * ☀️ **รอบบ่าย (Afternoon Session)**:
    * สวิตช์เปิด/ปิดรอบบ่าย กำหนดเวลาเริ่มและหมดเขตรอบบ่าย (เช่น `12:00 - 13:30 น.`) $\rightarrow$ สถานะ: **เช็คชื่อช่วงบ่าย**
* **ล็อกหน้าจออัตโนมัตินอกเวลาเรียน**:
  * หากอยู่นอกเวลาที่ตั้งไว้ ระบบจะ **ซ่อน QR Code และ OTP ทั้งหมด 100%** พร้อมแสดงกล่องล็อก `🔒 ขณะนี้ยังไม่เปิดให้เช็คชื่อสำหรับห้องนี้` ป้องกันนักศึกษาเช็คชื่อล่วงหน้า
* **ปุ่มด่วนสำหรับอาจารย์**:

## 🚀 ขั้นตอนการติดตั้งใช้งานบน Google Apps Script (Google Sheets)

### 1. เตรียมสเปรดชีต Google Sheets
1. เข้าไปที่ **[Google Sheets](https://sheets.new)** แล้วสร้างสเปรดชีตใหม่ (ตั้งชื่อตามต้องการ เช่น `ฐานข้อมูลเช็คชื่อนักศึกษา`)
2. ไปที่เมนู **ส่วนขยาย (Extensions)** ➔ **Apps Script**

### 2. นำเข้าโค้ดระบบ
1. ในหน้าต่างโปรเจกต์ Apps Script:
   * เปิดไฟล์ **`Code.gs`** ➔ ลบโค้ดเดิมออกทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ `Code.gs` ในโปรเจกต์นี้ไปวาง
   * กดเครื่องหมาย **`+`** ข้างๆ เมนู "ไฟล์" ➔ เลือก **HTML** ➔ ตั้งชื่อว่า **`index`** (ไม่ต้องพิมพ์ .html)
   * คัดลอกโค้ดจากไฟล์ `index.html` ในโปรเจกต์นี้ไปวางทับทั้งหมด
   * *(ทางเลือก)* หากต้องการใช้หน้ารายงานโพเดี้ยมแยก: กด `+` ➔ เลือก HTML ➔ ตั้งชื่อว่า `Report1.2.5` แล้วคัดลอกโค้ดจาก `Report1.2.5.html` ไปวาง
2. ไปที่เมนู **การตั้งค่าโปรเจกต์ (Project Settings)** (รูปฟันเฟืองด้านซ้าย) ➔ ติ๊กถูกที่ช่อง **"แสดงไฟล์ Manifest 'appsscript.json' ในโปรแกรมแก้ไข"**
3. กลับมาที่เมนู "โปรแกรมแก้ไข" (รูป `< >`) ➔ เปิดไฟล์ **`appsscript.json`** ➔ คัดลอกโค้ดจากไฟล์ `appsscript.json` ไปวางเพื่อตั้งค่า Timezone เป็น `Asia/Bangkok`
4. กดบันทึกโปรเจกต์ (Ctrl + S หรือไอคอนแผ่นดิสก์)

### 3. การทำให้ใช้งานได้ (Deploy as Web App)
1. กดปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy)** ที่มุมขวาบน ➔ เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกไอคอนรูปฟันเฟืองข้าง "เลือกประเภท" ➔ เลือก **เว็บแอป (Web app)**
3. ตั้งค่าการเผยแพร่:
   * **คำอธิบาย (Description)**: `ระบบเช็คชื่อนักศึกษา Smart Attendance v2.5`
   * **ดำเนินการในฐานะ (Execute as)**: `ฉัน (Me - บัญชี Google ของคุณ)`
   * **ผู้มีสิทธิ์เข้าถึง (Who has access)**: `ทุกคน (Anyone)` *(สำคัญมาก: เพื่อให้นักศึกษาเข้าเช็คชื่อได้โดยไม่ต้องล็อกอินบัญชี Google)*
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. กด **ให้สิทธิ์การเข้าถึง (Authorize access)** ➔ เลือกบัญชี Google ของคุณ ➔ กด **Advanced (ขั้นสูง)** ➔ กด **Go to ... (unsafe)** ➔ กด **Allow (อนุญาต)**
6. ระบบจะแสดง **URL เว็บแอป (Web app URL)** ให้คัดลอก URL นี้ไว้เพื่อนำไปแจกจ่ายให้นักศึกษาและอาจารย์ใช้งาน
