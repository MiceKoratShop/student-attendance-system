# 🎓 ระบบเช็คชื่อนักศึกษาออนไลน์ - Anti-Cheat & Smart Automated Schedule Edition

ระบบเช็คชื่อนักศึกษาออนไลน์ระดับองค์กร ออกแบบด้วยสถาปัตยกรรม **Mobile-First Glassmorphism** พร้อมระบบความปลอดภัยป้องกันการโกง 4 ชั้น (Dynamic TOTP 15s, GPS Geofencing, Device Token Binding, Live Camera Selfie) และระบบ **เช็คชื่อประจำวันอัตโนมัติตามปฏิทิน & ตารางสอน** พร้อมระบบแจ้งเตือนเข้ากลุ่ม LINE แบบ Flex Message อัจฉริยะ ใช้งานร่วมกับ Google Sheets หรือเปิดใช้งานเป็น Standalone PWA บน GitHub Pages

## 🌟 จุดเด่นและฟังก์ชันการทำงานหลัก

### 📅 1. ระบบเช็คชื่อประจำวันอัตโนมัติตามปฏิทิน & ตารางสอน (Automated Daily Schedule)
- **ตั้งค่าตารางเวลาได้อิสระตามห้องเรียน**:
  - **เลือกได้หลายห้องเรียนพร้อมกัน (Multi-Select Classrooms)**: เลือกระบุเฉพาะห้อง หรือเลือก `🌟 ทุกห้องเรียน` พร้อมปุ่ม `[ เลือกทั้งหมด ]`
  - **เลือกวันในสัปดาห์**: กำหนดวันเปิดใช้งาน (จันทร์–ศุกร์ หรือเสาร์–อาทิตย์)
  - **ดึงชื่อกิจกรรม/วิชาจากระบบเดิม (Dynamic Activity)**: เลือกจากกิจกรรมที่มีในระบบ (เช่น `เช็คชื่อมาเรียน`, `เช็คชื่อเข้าแถว`, `กิจกรรมโฮมรูม`, `กิจกรรมชมรม` ฯลฯ) หรือระบุชื่อวิชากำหนดเอง
- **กำหนดช่วงเวลาแบบแยกเฟสอัจฉริยะ (Time Windows)**:
  - 🌅 **รอบเช้า (Morning Session)**:
    - เริ่มเปิดเช็คชื่อ: `07:00 น.`
    - 🟢 **หมดเขตมาตรงเวลา:** `08:30 น.` $\rightarrow$ บันทึกสถานะ: **มาเรียน (Present)**
    - 🌸 **หมดเขตมาสาย:** `09:00 น.` $\rightarrow$ บันทึกสถานะ: **มาสาย (Late)**
  - ☀️ **รอบบ่าย (Afternoon Session)**:
    - มีปุ่ม **`[x] เปิดใช้งานรอบบ่าย`** สามารถเลือกเปิดหรือปิดเช็คชื่อช่วงบ่ายได้
    - กำหนดเวลาเปิดรอบบ่ายและเวลาหมดเขต (เช่น `12:00 - 13:30 น.`) $\rightarrow$ บันทึกกิจกรรม: **เช็คชื่อช่วงบ่าย**
- **ปุ่มด่วนสำหรับอาจารย์**:
  - `[ ⚡ คืนค่ามาตรฐานทุกห้อง (จันทร์-ศุกร์ 07:00-08:30 น.) ]` ตั้งค่าพร้อมใช้งานทันทีใน 1 คลิก
- **ระบบป้องกันและปลดล็อกหน้าจอนักศึกษาอัตโนมัติ**:
  - 🟢 **ห้องที่เปิดและอยู่ในช่วงเวลา**: ปลดล็อกหน้าจอ แสดง **QR Code ประจำคาบ**, **รหัส OTP ไดนามิก 6 หลัก**, **รหัสคาบ**, แถบนับถอยหลัง 15 วินาที พร้อมป้ายสถานะสด (มาเรียนตรงเวลา / มาสาย)
  - 🔒 **ห้องที่ไม่ได้ตั้งค่าหรืออยู่นอกเวลา**: **ซ่อน QR Code และ OTP ทั้งหมด 100%** พร้อมแสดงกล่องล็อก `🔒 ขณะนี้ยังไม่เปิดให้เช็คชื่อสำหรับห้องนี้` และปิดปุ่มถัดไป
  - 📋 **ปุ่มคัดลอกรวดเร็ว**: มีปุ่ม `[ 📋 คัดลอกรหัส OTP ]`, `[ 📋 คัดลอกรหัสคาบ ]` และปุ่ม `[ 📋 คัดลอกและกรอก OTP ทันที ]` ช่วยให้นักศึกษากรอกรหัสในขั้นตอนยืนยันได้ทันทีโดยไม่ต้องจำ

### 🛡️ 2. มาตรการป้องกันการโกง 4 ชั้น (Anti-Cheat Engine)
1. **Dynamic TOTP / Live QR Code**: รหัส OTP 6 หลักและ QR Code คำนวณแบบ Seed-based TOTP รีเฟรชทุก 15 วินาที สำหรับฉายหน้าจอโปรเจกเตอร์หรือแสดงบนจอเช็คชื่อ (ป้องกันการแคปหน้าจอส่งต่อ)
2. **GPS Geofencing**: ตรวจสอบพิกัด GPS จริงของนักศึกษาว่าอยู่ภายในรัศมีห้องเรียนที่กำหนด (คำนวณระยะทางด้วย Haversine Formula)
3. **Device Token Binding (1 เครื่อง / 1 บัญชี)**: ผูก Session กับฮาร์ดแวร์เบราว์เซอร์ ป้องกันการนำเครื่องเดียวไปล็อกอินเช็คชื่อแทนเพื่อน
4. **Live Selfie Camera**: บังคับเปิดกล้องหน้าถ่ายภาพสดแบบ Real-time (ปิดการเลือกรูปจาก Gallery ป้องกันการใช้รูปเก่า)

### 💬 3. ระบบแจ้งเตือนกลุ่ม LINE ผู้ปกครอง & อาจารย์ (LINE Flex Message 2.0)
- **การ์ดสรุปยอดเช็คชื่อ (LINE Flex Message)**:
  - ดีไซน์สวยงาม สัดส่วนชัดเจน อ่านง่ายบนมือถือ
  - สรุปยอดรวม: จำนวนคนทั้งหมด, มาเรียน, มาสาย, ลา, ขาดเรียน
  - 🟢 **แสดงรายชื่อผู้ที่มาเรียนตรงเวลา**: แสดงเลขที่, ชื่อ-นามสกุล, ห้องเรียน และ **เวลาที่ลงชื่อแบบกระชับ (เช่น ⏰ 08:35 น.)**
  - 🌸 **แสดงรายชื่อผู้ที่มาสาย**: แสดงชื่อและเวลาที่เข้าสายชัดเจน
- **Smart Webhook Assistant**:
  - บอททำงานเงียบในกลุ่ม ไม่ตอบกลับข้อความคุยทั่วไปในกลุ่ม
  - ตอบกลับเฉพาะคำสั่งของผู้ดูแลระบบ (เช่น `!id`, `/id`, `รหัสกลุ่ม`)
- **ระบบจดจำตัวกรองรายงานล่าสุด (Filter Persistence)**:
  - จดจำการเลือกห้องเรียน (เลือกได้หลายห้อง), รายวิชา/กิจกรรม และสถานะที่เลือกไว้ล่าสุด ไม่ต้องติ๊กเลือกใหม่ทุกครั้ง

### 🔒 4. ระบบจัดการฐานข้อมูล & ความปลอดภัย (Admin Security & Database Management)
- **ป๊อปอัปยืนยันรหัสผ่าน Admin ก่อนล้างฐานข้อมูล (Clean Reset Protection)**:
  - เมื่อกดปุ่ม `[ ล้างและเริ่มต้นระบบใหม่ (Clean Reset) ]` ระบบจะแสดงหน้าต่าง **Popup ตรวจสอบรหัสผ่าน Admin (`admin888`)** ก่อนดำเนินการเสมอ เพื่อป้องกันการกดลบข้อมูลโดยไม่ได้ตั้งใจ
- **นำเข้ารายชื่อนักเรียนจาก Excel / Copy-Paste**:
  - รองรับไฟล์ `.xlsx`, `.csv` และการคัดลอกตารางจาก Excel / Google Sheets วางลงระบบได้ทันที
  - ตาราง Interactive Preview แก้ไขชื่อ เลขที่ สลับแถว ลบแถว หรือจัดเลขที่อัตโนมัติก่อนบันทึก
- **ออกรายงาน PDF & Excel**:
  - สรุปการมาเรียนรายวัน รายสัปดาห์ รายเดือน แยกตามห้องเรียนและวิชา

## 🚀 วิธีการนำไปติดตั้งใช้งานบน Google Apps Script (ฐานข้อมูล Google Sheets)

1. เปิด **[Google Sheets](https://sheets.new)** สร้างสเปรดชีตใหม่
2. ไปที่เมนู **ส่วนขยาย (Extensions)** ➔ **Apps Script**
3. สร้างไฟล์ 2 ไฟล์ในโปรเจกต์:
   - **`Code.gs`**: คัดลอกโค้ดจาก `Code.gs` ไปวางทับทั้งหมด
   - **`Index.html`**: สร้างไฟล์ HTML ตั้งชื่อ `Index` แล้วคัดลอกโค้ดจาก `Index.html` ไปวางทับทั้งหมด
4. กดบันทึก (Ctrl + S)
5. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** ➔ **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
6. ตั้งค่าการเผยแพร่เว็บแอป:
   - **ประเภท (Type)**: เว็บแอป (Web app)
   - **คำอธิบาย (Description)**: `ระบบเช็คชื่อนักศึกษา v2.0`
   - **ดำเนินการในฐานะ (Execute as)**: `ฉัน (Me / เจ้าของบัญชี)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: `ทุกคน (Anyone)`
7. กด **ทำให้ใช้งานได้ (Deploy)** ➔ ให้สิทธิ์การเข้าถึง (Authorize Access)
8. คัดลอก **URL เว็บแอป (Web App URL)** ไปใช้งานหรือแจกจ่ายให้นักศึกษาและอาจารย์ได้ทันที

## 🌐 วิธีการนำขึ้น GitHub และเปิดใช้งาน GitHub Pages

### วิธีที่ 1: อัปโหลดผ่านหน้าเว็บ GitHub
1. เข้าสู่ระบบที่ **[GitHub.com](https://github.com)** แล้วสร้าง Repository ใหม่
2. ในหน้า Repository กด **Add file** ➔ **Upload files**
3. ลากไฟล์ `index.html`, `Code.gs`, `README.md` และไฟล์รูปภาพขึ้นไป แล้วกด **Commit changes**

### วิธีที่ 2: เปิดใช้งาน GitHub Pages
1. ในหน้า GitHub Repository ไปที่แท็บ **Settings** ➔ เมนูด้านซ้ายเลือก **Pages**
2. ในส่วน **Build and deployment** > **Branch**:
   - เลือก Branch: `main` (หรือ `master`)
   - เลือก Folder: `/ (root)`
3. กด **Save**
4. ระบบจะสร้างลิงก์สำหรับเข้าใช้งาน เช่น `https://username.github.io/repository-name/`
